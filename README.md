# Blinkit Grocery Store Analysis

## About the Project

This project is based on Blinkit grocery store data.

I used **SQL** to analyze the data and **Tableau** to create an interactive dashboard.

## Tools & Technologies

- SQL
- DBeaver
- Tableau

## Dataset

The dataset contains **8.5K+ grocery items** with information about:

- Item Type
- Fat Content
- Item MRP
- Outlet Type
- Outlet Size
- Outlet Location
- Outlet Establishment Year
- Item Sales

## Analysis

In this project, I analyzed:

- Product-wise sales
- Outlet-wise sales
- Sales by item type
- Sales by fat content
- Sales by outlet type
- Sales by outlet location
- Sales based on MRP
- Outlet establishment year

## Tableau Dashboard

Created an interactive Tableau dashboard with:

- KPIs
- Charts
- Filters
- Sales analysis
- Product and outlet analysis
